# Naveen A — Portfolio

A responsive portfolio website based on the details in the supplied resume.

## Files
- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and current year

## Run locally
Open `index.html` in your browser. For easier development, you can open the folder in VS Code and use the Live Server extension.

## Publish on GitHub Pages
1. Create a GitHub repository (for example, `naveen-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment section, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site and open the URL it provides.

## Before publishing
- Confirm that you want your phone number and email displayed publicly.
- Add project GitHub links or screenshots when available.
- Add your college graduation year if you want it shown.
